# Training Checklist

## Checklist đăng nhập và quyền

- [ ] Admin đăng nhập được
- [ ] Manager đăng nhập được
- [ ] Staff đăng nhập được
- [ ] Staff chỉ thấy chi nhánh mình
- [ ] Manager chỉ thấy dữ liệu chi nhánh mình
- [ ] Admin xem được toàn hệ thống

## Checklist vận hành Staff

- [ ] Staff vào được `Ming Customer Care`
- [ ] Staff xem được `Bảng điều hành`
- [ ] Staff mở được `Cần gọi hôm nay`
- [ ] Staff nhận task được
- [ ] Staff ghi nhận kết quả gọi được
- [ ] Staff hẹn gọi lại được
- [ ] Staff tạo được lịch sử CSKH
- [ ] Staff tạo được follow-up task sau khi hẹn gọi lại

## Checklist vận hành Manager

- [ ] Manager xem được dashboard chi nhánh
- [ ] Manager xem được task quá hạn
- [ ] Manager xem được khách VIP có nguy cơ
- [ ] Manager xem được lịch sử CSKH của chi nhánh
- [ ] Manager xem được log tin nhắn

## Checklist vận hành Admin

- [ ] Admin thấy app `CRM`
- [ ] Admin thấy app `Ming Customer Care`
- [ ] Admin mở được Dashboard Ming Customer Care
- [ ] Admin xem được toàn bộ khách hàng
- [ ] Admin xem được toàn bộ task
- [ ] Admin xem được toàn bộ cảnh báo
- [ ] Admin kiểm tra được cấu hình và connector
